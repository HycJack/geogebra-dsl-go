# GeoGebra kernel command names — the authoritative list.
#
# Extracted from GeoGebra's own source (see catalog.go for the exact command):
#   source/shared/common/src/main/java/org/geogebra/common/kernel/commands/Commands.java
#
# Upstream restructured this file: `Commands` used to be a pile of
# `public static final CommandName` constants and is now an
# `enum Commands implements CommandsConstants`, with the table indices moved
# to CommandsConstants. A script written against the old shape matches nothing,
# which is how the 2026-09-18 "hallucinated command" cleanup deleted nine real
# entries (Incenter/Circumcenter/... were reinstated as aliases right after).
#
# Enum constants are `Name(TABLE_X),`; the LAST one ends in `;` and the
# constructor `Commands(int table) {` must be excluded. Names differing only in
# case (SXX vs Sxx, PolyLine vs Polyline) are one command; this file keeps
# GeoGebra's own spelling and the loader upper-cases before matching.
#
# 549 commands, deduplicated case-insensitively. Regenerate by re-running the
# extraction in catalog.go's comment against a newer GeoGebra, then update this
# count. The coverage test reports any drift as a missing/extra name.
