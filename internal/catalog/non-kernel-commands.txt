# Names in the command table that are NOT GeoGebra kernel commands.
#
# This is the *other* side of the coverage check in kernel-commands.txt: the
# set difference `table - kernel` must equal this file, name for name. Every
# entry here needs a reason, because a table name with no kernel command behind
# it is either a typo for a real command or a hallucination that should be
# dropped — both are bugs, and both used to pass unnoticed.
#
# Two categories are represented:
#   parser-function  elementary functions from ParserFunctionsFactory. Not
#                    Commands enum members, but valid input-bar syntax, and
#                    Sin/Cos/Sqrt/... are among the most common things an AI
#                    emits. Rejecting them would fail correct scripts.
#   reserved-word    parser-level keywords rather than functions.
#
# 26 names, tab-separated as <NAME>\t<category>\t<reason>. Names are
# upper-cased by the loader; GeoGebra's own spelling is preserved here because
# the point of the file is to be readable next to the source.
#
# Regenerate: run the coverage test; every name it reports as unexplained
# belongs here with a reason, or in the table as an alias, or nowhere.
